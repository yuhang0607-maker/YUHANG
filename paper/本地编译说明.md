# 在 VS Code 编译论文

环境已配置：项目便携 TeX Live 2026、pdfLaTeX/BibTeX/latexmk、LaTeX Workshop。

1. 用 VS Code 的“文件 → 从文件打开工作区”打开本目录的 AIAA-Paper.code-workspace。也支持从整个 StudyOfSymmetricSweptWings 项目打开。
2. 打开 main.tex，按 Ctrl+Alt+B 编译。
3. 按 Ctrl+Alt+V，在右侧打开 PDF 预览。
4. 此后保存任意正文 .tex 会自动编译；已打开的预览会更新。

PDF 在 build/main.pdf，编译日志在 build/main.log。SyncTeX 已启用。
如果刚安装的扩展未加载，运行命令 Developer: Reload Window（开发人员：重新加载窗口）。

命令行备用方式（在本论文目录运行）：

    powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\build-paper.ps1

强制重新编译（安装新依赖后或需要重建时）：

    powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\build-paper.ps1 -Rebuild

编译脚本只给子进程设置 TeX 路径，不需要修改系统 PATH。
